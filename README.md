# Indian Real Estate Analytics Dashboard

# Project Overview
The Indian Real Estate Analytics Dashboard is a data analytics project designed to explore and analyze the Indian property market. It provides meaningful insights into property prices, location-wise trends, property distribution, and other key real estate metrics through interactive visualizations.
The dashboard helps users understand market patterns, compare property prices across different locations, and identify trends that can support better real estate investment and business decisions.

# Objectives
- Analyze property price trends across different Indian locations.
- Compare property prices based on geographical regions.
- Identify patterns and trends in the real estate market.
- Explore property-related metrics through interactive visualizations.
- Present meaningful insights to support data-driven decisions.

# Key Features
- Interactive dashboard with visual representations of real estate data.
- Location-wise property price analysis.
- Comparison of property prices across different regions.
- Analysis of property market trends.
- Data-driven insights for understanding the Indian real estate market.

# Tools & Technologies
MS Excel

# Project Outcome
This project demonstrates how data analytics and visualization can transform raw real estate data into meaningful insights, helping users understand property market trends and make informed decisions.
